# 01-tool-calling

Два учебных агента-администратора клиники. Оба ходят в Groq и записывают пациента через инструменты, без настоящей базы.

## Что умеет

**`agent.py`** — цикл tool calling на OpenAI SDK через совместимый API Groq (`https://api.groq.com/openai/v1`, модель `openai/gpt-oss-20b`).

- `get_free_slots(date)` — свободные окна на дату `YYYY-MM-DD`. Сейчас слоты заданы только на `2026-10-27`: 10:00, 12:00, 15:30.
- `book_appointment(name, phone, slot)` — записывает пациента. Слот в формате `YYYY-MM-DD HH:MM`.
- Перед записью агент спрашивает имя, телефон и услугу.
- История копится в списке `messages`. После команды `выход` диалог собирается в заявку `Booking` (имя, телефон, слот, услуга).

**`graph.py`** — тот же сценарий на LangGraph, модель `groq:openai/gpt-oss-20b`.

- Инструменты те же по смыслу: `get_free_slots(date)` и `book_appointment(name, date, time)`.
- Граф: узел модели → при необходимости узел инструментов → снова модель.
- Память диалога — `InMemorySaver`. Один и тот же `thread_id` помнит прошлые реплики, новый `thread_id` начинает разговор с нуля.

Ключ лежит в `.env`:

```
GROQ_API_KEY=ваш_ключ
```

## Установка на Windows

Нужен Python 3.12.

```powershell
cd C:\Users\user\Desktop\01-tool-calling
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

Если PowerShell не даёт активировать окружение, запускайте скрипты напрямую через `.\venv\Scripts\python.exe`.

## Запуск

Интерактивный агент:

```powershell
.\venv\Scripts\python.exe agent.py
```

Пишите реплики в консоль. Чтобы закончить и получить итоговую заявку, введите `выход`.

Демонстрация памяти LangGraph (три заранее заданных реплики, ввод не нужен):

```powershell
.\venv\Scripts\python.exe graph.py
```

## Пример диалога

`agent.py`:

```
Вы: Хочу записаться на завтра
  [инструмент] get_free_slots({'date': '2026-10-27'})
Бот: На 2026-10-27 свободны 10:00, 12:00 и 15:30. Напишите имя, телефон и услугу.

Вы: Дильмурад, +998901112233, консультация, на 10:00
  [инструмент] book_appointment({'name': 'Дильмурад', 'phone': '+998901112233', 'slot': '2026-10-27 10:00'})
Бот: Готово, вы записаны на 2026-10-27 в 10:00.

Вы: выход
Заявка: name='Дильмурад' phone='+998901112233' slot='2026-10-27 10:00' service='консультация'
```

`graph.py` показывает разницу памяти. В разговоре `1` бот помнит, что речь о пятнице, и записывает Дильмурада на первое окно. В разговоре `2` той же фразы недостаточно: пятницу он не знает.
